# Пример структуры JSON для продуктов в S3

## Структура продукта с галереей изображений

Каждый продукт в `products.json` должен иметь следующую структуру:

```json
{
  "id": "vm-01",
  "name": "Вакуумный эмульгатор VM-01",
  "globalCategory": "Оборудование для приготовления и хранения",
  "category": "Вакуумные эмульгаторы",
  "image": "images/products/vm-01.jpg",
  "galleryImages": [
    "images/products/vm-01.jpg",
    "images/products/vm-01-1.jpg",
    "images/products/vm-01-2.jpg",
    "images/products/vm-01-3.jpg"
  ],
  "description": "Высокоточный вакуумный эмульгатор для косметической промышленности с интеллектуальным PLC управлением.",
  "specs": {
    "ОБЪЕМ": "1000-3000 л",
    "МОЩНОСТЬ": "15-30 кВт",
    "СКОРОСТЬ": "0-3000 об/мин",
    "МАТЕРИАЛ": "Нержавеющая сталь 316L",
    "ТЕМПЕРАТУРА": "0-150°C",
    "ВАКУУМ": "≤ -0.095 МПа"
  },
  "fullDescription": "Профессиональный вакуумный эмульгатор для крупносерийного производства косметических и гигиенических продуктов. Обеспечивает высокую безопасность, точный контроль температуры и мощное гомогенное смешивание материалов.",
  "advantages": [
    {
      "icon": "shieldCheckmarkOutline",
      "title": "Высокое качество материалов",
      "description": "Использование сертифицированных материалов и компонентов нержавеющей стали 316L для максимальной долговечности"
    },
    {
      "icon": "speedometerOutline",
      "title": "Интеллектуальное PLC управление",
      "description": "Автоматический контроль всех параметров процесса с возможностью сохранения рецептур"
    },
    {
      "icon": "thermometerOutline",
      "title": "Точный контроль температуры",
      "description": "Система температурного контроля с точностью ±1°C в диапазоне от 0 до 150°C"
    },
    {
      "icon": "flashOutline",
      "title": "Высокая производительность",
      "description": "Мощное гомогенное смешивание до 3000 об/мин для крупносерийного производства"
    }
  ]
}
```

## Поля продукта

### Обязательные поля:
- `id` - уникальный идентификатор продукта (например, "vm-01")
- `name` - название продукта
- `category` - подкатегория продукта
- `image` - путь к главному изображению продукта (относительный путь из S3, например: "images/products/vm-01.jpg")
- `description` - краткое описание
- `specs` - объект со спецификациями продукта
- `fullDescription` - полное описание продукта

### Опциональные поля:
- `globalCategory` - общая категория для группировки (например, "Оборудование для приготовления и хранения")
- `galleryImages` - массив путей к изображениям для галереи (относительные пути из S3)
- `advantages` - массив преимуществ продукта

## Правила для galleryImages

1. **Формат путей**: Все пути должны быть относительными и начинаться с `images/products/`
2. **Именование файлов**: 
   - Главное изображение: `{product-id}.jpg` (например, `vm-01.jpg`)
   - Дополнительные изображения: `{product-id}-{номер}.jpg` (например, `vm-01-1.jpg`, `vm-01-2.jpg`)
3. **Порядок**: Первое изображение в массиве обычно совпадает с главным изображением (`image`)
4. **Минимум**: Если `galleryImages` не указан, будет использоваться только главное изображение

## Примеры путей для разных продуктов

### VM-01 (Вакуумный эмульгатор)
```json
{
  "image": "images/products/vm-01.jpg",
  "galleryImages": [
    "images/products/vm-01.jpg",
    "images/products/vm-01-1.jpg",
    "images/products/vm-01-2.jpg",
    "images/products/vm-01-3.jpg"
  ]
}
```

### PM-02 (Планетарный миксер)
```json
{
  "image": "images/products/pm-02.jpg",
  "galleryImages": [
    "images/products/pm-02.jpg",
    "images/products/pm-02-1.jpg",
    "images/products/pm-02-2.jpg"
  ]
}
```

### Продукт без галереи (будет использовано только главное изображение)
```json
{
  "image": "images/products/sr-04.jpg"
  // galleryImages отсутствует - будет использовано только главное изображение
}
```

## Структура файлов в S3

Для продукта `vm-01` файлы должны быть загружены в S3 следующим образом:

```
s3://stanley-co/
└── images/
    └── products/
        ├── vm-01.jpg      (главное изображение)
        ├── vm-01-1.jpg     (дополнительное изображение 1)
        ├── vm-01-2.jpg     (дополнительное изображение 2)
        └── vm-01-3.jpg     (дополнительное изображение 3)
```

## Важные замечания

1. **Все пути относительные**: Не используйте абсолютные пути или пути, начинающиеся с `/`
2. **Формат файлов**: Рекомендуется использовать `.jpg` для фотографий
3. **Совместимость**: Если `galleryImages` не указан, приложение автоматически использует только главное изображение
4. **Порядок важен**: Изображения в галерее будут отображаться в том порядке, в котором они указаны в массиве
