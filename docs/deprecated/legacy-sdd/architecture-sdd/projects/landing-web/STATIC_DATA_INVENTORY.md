# Static Data Inventory

| Source | Data | Target |
| --- | --- | --- |
| S3 products JSON | products, categories, specs, images, videos | backend catalog |
| S3 news/articles JSON | content items and blocks | backend content |
| S3 carousel JSON | slides | backend slide |
| `Header.tsx` arrays | menu/anchors | menu API |
| `Footer.tsx` | footer text, contacts | site/contact/menu |
| `ContactInfo.tsx` | contacts/social | contact/social |
| `AboutPage.tsx`, `CompanyIntro.tsx` | company text, competences | page sections |
| `PrivacyPolicyPage.tsx` | legal text | page/legal document |
| legacy components | FAQ, gallery, testimonials, applications, features | legacy blocks |
| public logo/favicon | branding | site/media settings |

Local `src/data` and `src/data_v2` are comparison inputs only.
