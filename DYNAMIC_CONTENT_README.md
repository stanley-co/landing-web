# Динамическая загрузка контента из S3

## Быстрый старт

Проект настроен на загрузку данных о продуктах и новостях из Yandex Cloud S3-хранилища. Это позволяет обновлять контент без редеплоя приложения.

## 📦 Что было реализовано

### 1. Универсальная утилита загрузки данных

Файл: `src/utils/fetchStaticData.ts`

- ✅ Функция `fetchStaticData<T>(url: string)` для загрузки JSON
- ✅ Автоматическое кэширование (5 минут)
- ✅ Обработка ошибок
- ✅ Консольное логирование (loading, success, error)
- ✅ Константы URL для S3

### 2. Типизация данных

Файлы: 
- `src/types/product.ts` - типы для продуктов
- `src/types/news.ts` - типы для новостей

Новые поля:
- `Product.advantages[]` - массив преимуществ продукта (опционально)
- Каждое преимущество содержит: `icon`, `title`, `description`

### 3. Обновленные компоненты

**Страницы:**
- ✅ `ProductDetailPage` - загрузка и отображение продукта из S3
- ✅ `EquipmentPage` - каталог продуктов из S3
- ✅ `NewsPage` - список новостей из S3
- ✅ `NewsArticlePage` - отдельная статья из S3

**Компоненты:**
- ✅ `ProductDescription` - использует advantages из данных продукта с fallback
- ✅ `NewsPreview` - последние 3 новости из S3
- ✅ `ProductsPreview` - первые 4 продукта из S3

### 4. Индикаторы загрузки и обработка ошибок

- Spinner во время загрузки
- Graceful fallback при ошибках
- Информативные сообщения об ошибках

### 5. Расширенные данные о продуктах

Файл: `src/data/products-with-advantages.json`

Каждый продукт теперь имеет 3-4 уникальных преимущества с:
- Иконкой (из библиотеки ionicons)
- Заголовком
- Описанием

## 🚀 URL S3-хранилища

```typescript
PRODUCTS: 'https://storage.yandexcloud.net/stanley-co/data/products/products.json'
NEWS: 'https://storage.yandexcloud.net/stanley-co/news/news.json'
```

## 📝 Как обновить контент

1. **Отредактируйте JSON файл** с данными
2. **Проверьте валидность** JSON
3. **Загрузите в S3** (см. подробную документацию в `S3_DATA_MANAGEMENT.md`)
4. **Обновите страницу** (или подождите 5 минут для истечения кэша)

## 📖 Подробная документация

См. файл **`S3_DATA_MANAGEMENT.md`** для:
- Полной структуры данных
- Списка доступных иконок
- Инструкций по загрузке в S3
- Примеров использования AWS/Yandex CLI
- Информации о кэшировании и логировании

## ✨ Преимущества решения

- 🔄 **Нет необходимости в редеплое** - просто обновите JSON в S3
- ⚡ **Быстрая загрузка** - кэширование на 5 минут снижает нагрузку
- 📊 **Подробное логирование** - все операции видны в консоли
- 🛡️ **Graceful degradation** - fallback при ошибках или отсутствии данных
- 🎨 **Гибкая структура** - каждый продукт может иметь свои уникальные преимущества
- 📱 **Работает везде** - клиентская загрузка данных

4. **Удалите старые импорты** - после успешного тестирования можно удалить старые JSON файлы из репозитория

## 💡 Совет

Для тестирования изменений перед загрузкой в S3, временно измените URL в `fetchStaticData.ts` на локальные файлы.
