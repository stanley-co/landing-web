# API Conventions

Prefixes:

- `/api/v1/public/**`
- `/api/v1/auth/**`
- `/api/v1/admin/**`

Conventions:

- JSON UTF-8;
- ISO-8601 timestamps;
- public aggregate paths accept the UUID generated by backend and, for imported rows, the immutable nullable `externalId`; UUID resolution takes precedence;
- create requests never contain `id`, `code` or `externalId`; those values are server-owned;
- pagination: `page`, `size`, `sort`;
- search query: `q` or `search`;
- filters are explicit query params;
- public endpoints return only `ACTIVE` content;
- admin endpoints may return all statuses.
- media list filters are explicit (`q`, `mediaType`, `mimeType`, `status`, `used`, `entityType`, `entityId`, `uploadedBy`, dates and `sort`), and reference selectors use paginated server-side search.
