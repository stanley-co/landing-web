# Definition Of Done

A task is done when:

- implementation follows ADR and project SDD;
- API contract updated or verified;
- database migrations added when schema changes;
- validation and error handling implemented;
- RBAC applied for admin actions;
- audit added for writes;
- tests added or updated;
- docs updated for changed behavior;
- local compose path works if runtime project is affected;
- acceptance criteria are checked.
