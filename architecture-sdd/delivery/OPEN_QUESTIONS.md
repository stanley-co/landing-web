# Open Questions

Resolved MVP scope is recorded in [MVP scope decisions](../MVP_SCOPE_DECISIONS_2026-07-18.md); it must not block implementation.

**DEFERRED UNTIL DEPLOYMENT PHASE:**

- final production domains for API/admin;
- production SMTP provider and sender address (the MVP recipient list is configured locally; no secret is required);
- exact production S3 bucket/access policy;
- whether public files are direct S3/CDN URLs or backend-proxied;
- first-release list of public PDF documents/certificates;
- final admin visual theme/brand tokens;
- whether `CONTENT_READER` may view leads in production.
