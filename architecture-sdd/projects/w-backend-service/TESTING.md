# Testing

Use JUnit 5, Mockito, Spring Boot Test, MockMvc/WebTestClient, Testcontainers PostgreSQL, MinIO/S3 test container.

Required:

- module unit tests;
- repository tests;
- controller tests;
- security/RBAC tests;
- migration-support tests;
- upload tests;
- notification email tests with Mailpit/mock;
- contract tests against OpenAPI.
