# Шаблоны контента для сайта

Этот каталог содержит шаблоны для заполнения контента каждой страницы сайта.

## Структура шаблонов

1. **01-home-page.md** - Главная страница
2. **02-about-page.md** - Страница "О компании"
3. **03-equipment-page.md** - Страница "Оборудование"
4. **04-contacts-page.md** - Страница "Контакты"
5. **05-news-page.md** - Страница "Новости"
6. **06-information-page.md** - Страница "Информация"
7. **07-product-detail-page.md** - Страница детального просмотра продукта
8. **08-article-detail-page.md** - Страница детального просмотра новости/статьи

## Как использовать шаблоны

1. Откройте нужный шаблон для страницы
2. Заполните все поля, указанные в шаблоне
3. Следуйте рекомендациям и примерам
4. Сохраните заполненный контент в соответствующие файлы данных

## Файлы данных

Контент сохраняется в следующих файлах:

- `src/data/products.json` - данные о продуктах/оборудовании
- `src/data/news.json` - данные о новостях
- `src/data/articles.json` - данные о статьях
- `src/data/carousel.json` - данные для карусели на странице оборудования

## Общие рекомендации

1. **Тон и стиль:**
   - Профессиональный, но доступный
   - Избегайте излишне технических терминов без объяснений
   - Используйте простой и понятный язык

2. **Длина текстов:**
   - Заголовки: 3-8 слов
   - Подзаголовки: 10-20 слов
   - Абзацы: 2-4 предложения

3. **Изображения:**
   - Формат: JPG или PNG
   - Разрешение: минимум 1920x1080 для фоновых, 800x600 для обычных
   - Оптимизация: сжатие для веб-использования

4. **Призывы к действию (CTA):**
   - Используйте глаголы действия: "Перейти", "Смотреть", "Узнать", "Связаться"
   - Делайте их конкретными и понятными

5. **Актуальность:**
   - Регулярно обновляйте контент
   - Проверяйте актуальность информации
   - Удаляйте устаревшие данные

## Порядок заполнения

Рекомендуемый порядок заполнения:

1. Начните с главной страницы (01-home-page.md)
2. Заполните страницу "О компании" (02-about-page.md)
3. Добавьте информацию об оборудовании (03-equipment-page.md)
4. Укажите контактную информацию (04-contacts-page.md)
5. Добавьте новости (05-news-page.md)
6. Создайте полезные статьи (06-information-page.md)

## Вопросы и помощь

Если у вас возникли вопросы по заполнению шаблонов, обратитесь к разработчику сайта.

## Форматы данных

Все данные сохраняются в формате JSON. Убедитесь, что:
- JSON валиден (можно проверить на jsonlint.com)
- Используются правильные кавычки (двойные)
- Нет лишних запятых
- Правильная структура вложенности
