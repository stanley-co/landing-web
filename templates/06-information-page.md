## Информация для каждой статьи

Для каждой статьи в файле `articles.json` необходимо указать:

### Основная информация

1. **ID статьи:**
   ```
   [Уникальный идентификатор]
   Пример: "2025-01-optimization-guide"
   Формат: год-месяц-краткое-название (латиница, без пробелов)
   ```

2. **Заголовок статьи:**
   ```
   [Полный заголовок статьи]
   Пример: "Руководство по оптимизации производственных процессов"
   Длина: 5-15 слов
   ```

3. **Дата публикации:**
   ```
   [Дата в формате YYYY-MM-DD]
   Пример: "2025-01-15"
   ```

4. **Категория:**
   ```
   [Название категории]
   Пример: "Статьи"
   Примечание: Обычно все статьи имеют категорию "Статьи"
   ```

5. **Изображение для превью:**
   ```
   [Путь к изображению]
   Пример: "images/articles/2025-01-optimization-guide.jpg"
   Размер: минимум 800x600px
   ```

6. **Краткое описание (превью):**
   ```
   [Краткое описание для карточки статьи]
   Пример: "Подробное руководство по оптимизации производственных процессов с использованием современного оборудования. Узнайте, как повысить эффективность и снизить затраты."
   Длина: 1-3 предложения (150-250 символов)
   ```

### Содержание статьи (content)

Содержание статьи состоит из блоков. Каждый блок может быть одного из типов:

#### Тип 1: Параграф (paragraph)

```
{
  "type": "paragraph",
  "text": "[Введите текст параграфа]"
}
```

**Пример:**
```json
{
  "type": "paragraph",
  "text": "Оптимизация производственных процессов — ключевой фактор успеха современного производства. В этой статье мы рассмотрим основные принципы и методы оптимизации."
}
```

**Рекомендации:**
- Длина: 3-7 предложений
- Используйте структурированные абзацы
- Каждый абзац должен раскрывать одну мысль

---

#### Тип 2: Изображение (image)

```
{
  "type": "image",
  "src": "[Путь к изображению]",
  "caption": "[Подпись к изображению (опционально)]"
}
```

**Пример:**
```json
{
  "type": "image",
  "src": "images/articles/content/2025-01-optimization-guide-content-1.jpg",
  "caption": "Современное производственное оборудование."
}
```

**Рекомендации:**
- Размер: минимум 1200x800px
- Формат: JPG или PNG
- Подпись: 1-2 предложения, описывающие изображение
- Используйте изображения для иллюстрации ключевых моментов

---

#### Тип 3: Цитата (quote)

```
{
  "type": "quote",
  "text": "[Текст цитаты]"
}
```

**Пример:**
```json
{
  "type": "quote",
  "text": "«Оптимизация процессов — это не разовое мероприятие, а постоянная работа по улучшению», — отмечают эксперты отрасли."
}
```

**Рекомендации:**
- Используйте для выделения важных мыслей
- Указывайте источник, если возможно
- Длина: 1-3 предложения

---

#### Тип 4: Ссылка (link)

```
{
  "type": "link",
  "url": "[URL ссылки]",
  "linkText": "[Текст ссылки]",
  "text": "[Текст до ссылки]"
}
```

**Пример:**
```json
{
  "type": "link",
  "url": "https://example.com/optimization-guide",
  "linkText": "Подробное руководство по оптимизации",
  "text": "Для более детального изучения темы рекомендуем ознакомиться с полным руководством на нашем ресурсе."
}
```

**Рекомендации:**
- Используйте для ссылок на дополнительные материалы
- Внешние ссылки должны открываться в новой вкладке
- Проверяйте актуальность ссылок

## Структура статьи

Рекомендуемая структура статьи:

1. **Введение (1-2 параграфа)**
   - Проблема или тема статьи
   - Цель статьи
   - Что читатель узнает

2. **Основная часть (4-8 параграфов)**
   - Основные разделы с подзаголовками (в тексте)
   - Детальное описание темы
   - Примеры и кейсы
   - Изображения для иллюстрации

3. **Практические советы (2-4 параграфа)**
   - Конкретные рекомендации
   - Пошаговые инструкции (если применимо)
   - Лучшие практики

4. **Заключение (1-2 параграфа)**
   - Резюме основных моментов
   - Призыв к действию
   - Дополнительные ресурсы

5. **Ссылки (опционально)**
   - Ссылки на дополнительные материалы
   - Связанные статьи
   - Полезные ресурсы

## Рекомендации по написанию статей

1. **Заголовок:**
   - Информативный и привлекательный
   - Отражает содержание статьи
   - Может содержать вопрос или обещание пользы
   - 5-15 слов

2. **Превью:**
   - Краткое, но информативное
   - Побуждает прочитать статью
   - Указывает на пользу для читателя
   - 150-250 символов

3. **Содержание:**
   - Структурированное и логичное
   - Используйте простой и понятный язык
   - Избегайте излишне технических терминов без объяснений
   - Разбивайте текст на короткие абзацы
   - Используйте списки и выделения для важной информации

4. **Изображения:**
   - Высокое качество
   - Релевантные к содержанию
   - С подписями для лучшего понимания
   - Используйте диаграммы и схемы для сложных концепций

5. **Длина статьи:**
   - Минимум: 500 слов
   - Идеально: 1000-2000 слов
   - Для подробных руководств: 2000+ слов

6. **SEO оптимизация:**
   - Используйте ключевые слова естественным образом
   - Создавайте полезный и уникальный контент
   - Структурируйте текст с помощью заголовков

---

## Частота публикаций

**Рекомендации:**
- Минимум 1 статья в месяц для поддержания активности
- Идеально: 2-3 статьи в месяц
- Публикуйте статьи на актуальные темы
- Отвечайте на вопросы клиентов в статьях
- Создавайте серии статей на связанные темы
