## Секция "Галерея изображений" (ProductGallery)

### Изображения продукта

**Примечание:** В текущей версии используются тестовые изображения. Для полноценной работы необходимо указать реальные изображения.

Для каждого продукта рекомендуется подготовить:

1. **Основное изображение:**
   ```
   [Путь к основному изображению]
   Пример: "images/products/vm-01/main.jpg"
   Размер: минимум 1920x1080px
   ```

2. **Дополнительные изображения (минимум 2-3):**
   ```
   Изображение 1: "images/products/vm-01/view-1.jpg"
   Изображение 2: "images/products/vm-01/view-2.jpg"
   Изображение 3: "images/products/vm-01/view-3.jpg"
   ```

3. **Детальные изображения (опционально):**
   ```
   Деталь 1: "images/products/vm-01/detail-1.jpg"
   Деталь 2: "images/products/vm-01/detail-2.jpg"
   ```

**Рекомендации по изображениям:**
- Разные ракурсы продукта
- Крупные планы важных деталей
- Продукт в работе (если возможно)
- Высокое качество и профессиональная фотография
- Единый стиль для всех изображений

## Секция "Описание продукта" (ProductDescription)

### Название продукта
```
[Заполняется автоматически из products.json]
Поле: "name"
```

### Краткое описание
```
[Заполняется автоматически из products.json]
Поле: "description"
```

### Полное описание
```
[Заполняется автоматически из products.json]
Поле: "fullDescription"
Пример: "Профессиональный вакуумный эмульгатор для крупносерийного производства косметических и гигиенических продуктов. Обеспечивает высокую безопасность, точный контроль температуры и мощное гомогенное смешивание материалов."
```

### Преимущества продукта
```
[Заполняется автоматически из products.json]
Поле: "advantages"
```

Для каждого преимущества указывается:
- **Иконка:** Название иконки из библиотеки Ionicons
- **Заголовок:** Краткий заголовок (3-6 слов)
- **Описание:** Подробное описание (1-2 предложения)

**Пример:**
```json
{
  "icon": "shieldCheckmarkOutline",
  "title": "Высокое качество материалов",
  "description": "Использование сертифицированных материалов и компонентов нержавеющей стали 316L для максимальной долговечности"
}
```

**Рекомендации:**
- Указывайте 4 преимущества для каждого продукта
- Фокусируйтесь на выгодах для клиента
- Используйте конкретные факты и цифры
- Избегайте общих фраз

## Секция "Технические характеристики" (ProductSpecs)

### Характеристики продукта
```
[Заполняется автоматически из products.json]
Поле: "specs"
```

**Формат:**
```json
{
  "ОБЪЕМ": "1000-3000 л",
  "МОЩНОСТЬ": "15-30 кВт",
  "СКОРОСТЬ": "0-3000 об/мин",
  "МАТЕРИАЛ": "Нержавеющая сталь 316L",
  "ТЕМПЕРАТУРА": "0-150°C",
  "ВАКУУМ": "≤ -0.095 МПа"
}
```

**Рекомендации:**
- Названия характеристик в ВЕРХНЕМ РЕГИСТРЕ
- Указывайте диапазоны значений, если применимо
- Используйте стандартные единицы измерения
- Будьте точными и честными
- Включайте все важные характеристики

**Типичные характеристики:**
- Объем/Емкость
- Мощность
- Скорость/Производительность
- Материал изготовления
- Температурный диапазон
- Давление/Вакуум
- Габариты
- Вес
- Электропитание
- Управление

## Структура файла products.json

Для каждого продукта необходимо заполнить следующую структуру:

```json
{
  "id": "vm-01",
  "name": "Вакуумный эмульгатор VM-01",
  "globalCategory": "Оборудование для приготовления и хранения",
  "category": "Вакуумные эмульгаторы",
  "image": "images/products/vm-01.jpg",
  "description": "Краткое описание для карточки",
  "specs": {
    "ХАРАКТЕРИСТИКА1": "Значение1",
    "ХАРАКТЕРИСТИКА2": "Значение2"
  },
  "fullDescription": "Полное описание продукта",
  "advantages": [
    {
      "icon": "iconName",
      "title": "Заголовок преимущества",
      "description": "Описание преимущества"
    }
  ]
}
```

**Подробные инструкции:** См. шаблон `03-equipment-page.md`

## Примеры хороших описаний

### Хорошее описание:
"Профессиональный вакуумный эмульгатор для крупносерийного производства косметических и гигиенических продуктов. Обеспечивает высокую безопасность, точный контроль температуры и мощное гомогенное смешивание материалов."

### Плохое описание:
"Хорошее оборудование для производства."

**Различия:**
- Хорошее описание конкретное и информативное
- Указывает на применение и преимущества
- Использует профессиональную терминологию
- Побуждает к действию

## Обновление информации

**Когда обновлять:**
- При изменении характеристик продукта
- При появлении новых версий
- При изменении цены или условий поставки
- При получении новых сертификатов
- При добавлении новых преимуществ

**Как обновлять:**
- Редактируйте файл `products.json`
- Обновляйте изображения при необходимости
- Проверяйте актуальность всех данных
