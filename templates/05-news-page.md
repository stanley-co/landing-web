## Информация для каждой новости

Для каждой новости в файле `news.json` необходимо указать:

### Основная информация

1. **ID новости:**
   ```
   [Уникальный идентификатор]
   Пример: "2025-04-vacuum-line"
   Формат: год-месяц-краткое-название (латиница, без пробелов)
   ```

2. **Заголовок новости:**
   ```
   [Полный заголовок новости]
   Пример: "Запущена новая вакуумная линия Stanley VM-300"
   Длина: 5-15 слов
   ```

3. **Дата публикации:**
   ```
   [Дата в формате YYYY-MM-DD]
   Пример: "2025-04-18"
   ```

4. **Категория:**
   ```
   [Название категории из списка выше]
   Пример: "Продукты"
   ```

5. **Изображение для превью:**
   ```
   [Путь к изображению]
   Пример: "images/news/2025-04-vacuum-line.jpg"
   Размер: минимум 800x600px
   ```

6. **Краткое описание (превью):**
   ```
   [Краткое описание для карточки новости]
   Пример: "Компания Stanley запустила в производство вакуумную эмульгационную установку нового поколения VM-300, которая обеспечивает более высокую степень гомогенизации и автоматический контроль параметров процесса."
   Длина: 1-3 предложения (100-200 символов)
   ```

---

### Содержание новости (content)

Содержание новости состоит из блоков. Каждый блок может быть одного из типов:

#### Тип 1: Параграф (paragraph)

```
{
  "type": "paragraph",
  "text": "[Введите текст параграфа]"
}
```

**Пример:**
```json
{
  "type": "paragraph",
  "text": "Компания Stanley представила новую модель вакуумной установки VM-300, которая обеспечивает более высокую степень гомогенизации и автоматический контроль параметров процесса."
}
```

**Рекомендации:**
- Длина: 2-5 предложений
- Используйте короткие абзацы для лучшей читаемости
- Разбивайте длинные тексты на несколько параграфов

---

#### Тип 2: Изображение (image)

```
{
  "type": "image",
  "src": "[Путь к изображению]",
  "caption": "[Подпись к изображению (опционально)]"
}
```

**Пример:**
```json
{
  "type": "image",
  "src": "images/news/content/2025-04-vacuum-line-content-1.jpg",
  "caption": "Новая установка Stanley VM-300 на производственной площадке."
}
```

**Рекомендации:**
- Размер: минимум 1200x800px
- Формат: JPG или PNG
- Подпись: 1-2 предложения, описывающие изображение
- Размещайте изображения между параграфами для лучшей структуры

---

#### Тип 3: Цитата (quote)

```
{
  "type": "quote",
  "text": "[Текст цитаты]"
}
```

**Пример:**
```json
{
  "type": "quote",
  "text": "«Мы гордимся результатом — VM-300 сочетает энергоэффективность и интеллектуальное управление процессами», — отметил технический директор компании."
}
```

**Рекомендации:**
- Используйте кавычки в тексте
- Указывайте автора цитаты, если возможно
- Длина: 1-3 предложения

---

#### Тип 4: Ссылка (link)

```
{
  "type": "link",
  "url": "[URL ссылки]",
  "linkText": "[Текст ссылки]",
  "text": "[Текст до ссылки]"
}
```

**Пример:**
```json
{
  "type": "link",
  "url": "https://example.com/optimization-guide",
  "linkText": "Подробное руководство по оптимизации",
  "text": "Для более детального изучения темы рекомендуем ознакомиться с полным руководством на нашем ресурсе."
}
```

**Рекомендации:**
- Используйте для ссылок на дополнительные материалы
- Убедитесь, что URL корректный
- Текст ссылки должен быть понятным и описательным

## Структура новости

Рекомендуемая структура новости:

1. **Вступление (1-2 параграфа)**
   - Основная информация о событии
   - Контекст и важность

2. **Основная часть (2-4 параграфа)**
   - Детали события
   - Технические характеристики (если применимо)
   - Изображения для иллюстрации

3. **Цитаты (1-2 цитаты)**
   - Мнения экспертов
   - Комментарии руководства

4. **Заключение (1 параграф)**
   - Перспективы
   - Дополнительная информация

5. **Ссылки (опционально)**
   - Ссылки на дополнительные материалы
   - Связанные новости или статьи

---

## Рекомендации по написанию новостей

1. **Заголовок:**
   - Информативный и привлекательный
   - Отражает суть новости
   - 5-15 слов

2. **Превью:**
   - Краткое, но информативное
   - Побуждает прочитать полную новость
   - 100-200 символов

3. **Содержание:**
   - Используйте простой и понятный язык
   - Избегайте излишне технических терминов без объяснений
   - Разбивайте текст на короткие абзацы
   - Используйте подзаголовки для длинных новостей

4. **Изображения:**
   - Высокое качество
   - Релевантные к содержанию
   - С подписями для лучшего понимания

5. **Актуальность:**
   - Публикуйте новости своевременно
   - Обновляйте устаревшую информацию
   - Удаляйте или архивируйте старые новости

---

## Частота публикаций

**Рекомендации:**
- Минимум 1-2 новости в месяц для поддержания активности
- Идеально: 3-4 новости в месяц
- Публикуйте новости о:
  - Новых продуктах и разработках
  - Участии в выставках и мероприятиях
  - Достижениях и наградах
  - Партнерствах и сотрудничестве
  - Расширении производства
  - Сертификациях и стандартах

---

## Категории новостей (детализация)

### Продукты
Новости о новых продуктах, обновлениях существующих моделей, технических характеристиках.

### События
Участие в выставках, конференциях, семинарах, презентациях.

### Производство
Расширение производственных мощностей, открытие новых цехов, модернизация оборудования.

### Партнерство
Новые партнерства, сотрудничество с другими компаниями, дилерские соглашения.

### Награды и достижения
Полученные награды, сертификаты, достижения компании.

### Технологии
Новые технологии, инновации, R&D разработки.
