# Шаблон контента: Страница детального просмотра новости/статьи

## Общая информация

**Примечание:** Контент для страницы новости/статьи заполняется в файлах `news.json` (для новостей) или `articles.json` (для статей). На этой странице отображается полное содержание выбранной новости или статьи.

---

## Секция "Заголовок статьи" (ArticleHero)

### Заголовок
```
[Заполняется автоматически из news.json или articles.json]
Поле: "title"
Пример: "Запущена новая вакуумная линия Stanley VM-300"
```

### Дата публикации
```
[Заполняется автоматически]
Поле: "date"
Формат: YYYY-MM-DD
Пример: "2025-04-18"
```

### Категория
```
[Заполняется автоматически]
Поле: "category"
Пример: "Продукты"
```

### Изображение
```
[Заполняется автоматически]
Поле: "image"
Пример: "images/news/2025-04-vacuum-line.jpg"
```

---

## Секция "Содержание статьи" (ArticleBody)

### Блоки контента

Содержание состоит из блоков разных типов. Подробные инструкции по заполнению см. в шаблонах:
- `05-news-page.md` - для новостей
- `06-information-page.md` - для статей

**Типы блоков:**
1. **Параграф** - текстовые абзацы
2. **Изображение** - фотографии с подписями
3. **Цитата** - выделенные цитаты
4. **Ссылка** - ссылки на дополнительные материалы

---

## Секция "Поделиться" (ArticleShare)

### Заголовок секции
```
[Заполняется автоматически]
Пример: "Поделиться статьей"
```

**Примечание:** Секция содержит кнопки для sharing в социальных сетях (автоматически генерируется).

---

## Секция "Похожие новости" (RelatedNews)

### Заголовок секции
```
[Заполняется автоматически]
Пример: "Похожие новости"
```

**Примечание:** На странице отображаются другие новости/статьи из соответствующих файлов, исключая текущую.

**Рекомендации:**
- Создавайте связанные новости/статьи на похожие темы
- Используйте одинаковые категории для группировки
- Добавляйте теги (если функционал будет добавлен)

---

## Рекомендации по структуре контента

### Для новостей:
1. Вступление (1-2 параграфа)
2. Основная часть (2-4 параграфа)
3. Изображения для иллюстрации
4. Цитаты экспертов
5. Заключение (1 параграф)

### Для статей:
1. Введение (1-2 параграфа)
2. Основная часть (4-8 параграфов)
3. Практические советы (2-4 параграфа)
4. Изображения и схемы
5. Заключение (1-2 параграфа)
6. Ссылки на дополнительные материалы

---

## Дополнительные рекомендации

1. **Длина контента:**
   - Новости: 300-800 слов
   - Статьи: 1000-2000+ слов

2. **Изображения:**
   - Минимум 1-2 изображения на статью
   - Высокое качество (1200x800px+)
   - Релевантные подписи

3. **Структура:**
   - Используйте короткие абзацы
   - Разбивайте длинные тексты
   - Добавляйте визуальные элементы

4. **SEO:**
   - Используйте ключевые слова естественно
   - Создавайте уникальный контент
   - Добавляйте мета-описания
