## Разделы оборудования

**Примечание:** Разделы оборудования создаются автоматически на основе данных из файла `products.json`. Каждый раздел соответствует глобальной категории оборудования.

### Структура разделов

Оборудование группируется по следующим глобальным категориям:

1. **Оборудование для приготовления и хранения**
   - Вакуумные эмульгаторы
   - Планетарные миксеры
   - Реакторы / Промышленные смесители

2. **Фасовочное оборудование**
   - Дозирующие системы
   - Фасовочные автоматы
   - Упаковочные линии

3. **Насосное оборудование**
   - Центробежные насосы
   - Поршневые насосы
   - Винтовые насосы

4. **СИП станции**
   - Мобильные СИП станции
   - Стационарные СИП станции
   - Компактные СИП станции

5. **Лабораторное оборудование**
   - Лабораторные миксеры
   - Лабораторные реакторы
   - Лабораторные сушильные шкафы

**Примечание:** Вы можете добавить новые категории или изменить существующие. Каждая категория будет отображаться как отдельный раздел на странице.

## Информация для каждого продукта

Для каждого продукта в файле `products.json` необходимо указать:

### Основная информация

1. **ID продукта:**
   ```
   [Уникальный идентификатор]
   Пример: "vm-01"
   Формат: буквы-цифры, без пробелов
   ```

2. **Название продукта:**
   ```
   [Полное название продукта]
   Пример: "Вакуумный эмульгатор VM-01"
   ```

3. **Глобальная категория:**
   ```
   [Категория для группировки]
   Пример: "Оборудование для приготовления и хранения"
   ```

4. **Категория (подкатегория):**
   ```
   [Подкатегория продукта]
   Пример: "Вакуумные эмульгаторы"
   ```

5. **Изображение:**
   ```
   [Путь к изображению]
   Пример: "images/products/vm-01.jpg"
   ```

6. **Краткое описание:**
   ```
   [Краткое описание для карточки продукта]
   Пример: "Высокоточный вакуумный эмульгатор для косметической промышленности с интеллектуальным PLC управлением."
   Длина: 1-2 предложения
   ```

### Полное описание

7. **Полное описание:**
   ```
   [Подробное описание продукта]
   Пример: "Профессиональный вакуумный эмульгатор для крупносерийного производства косметических и гигиенических продуктов. Обеспечивает высокую безопасность, точный контроль температуры и мощное гомогенное смешивание материалов."
   Длина: 2-4 предложения
   ```

### Технические характеристики

8. **Технические характеристики (specs):**
   ```
   Укажите характеристики в формате:
   "Характеристика": "Значение"
   
   Примеры:
   "ОБЪЕМ": "1000-3000 л"
   "МОЩНОСТЬ": "15-30 кВт"
   "СКОРОСТЬ": "0-3000 об/мин"
   "МАТЕРИАЛ": "Нержавеющая сталь 316L"
   "ТЕМПЕРАТУРА": "0-150°C"
   "ВАКУУМ": "≤ -0.095 МПа"
   
   Примечание: Названия характеристик должны быть в ВЕРХНЕМ РЕГИСТРЕ
   ```

### Преимущества

9. **Преимущества продукта (advantages):**
   
   Для каждого преимущества укажите:
   
   - **Иконка:** [Название иконки из библиотеки Ionicons]
     Пример: "shieldCheckmarkOutline"
     Список доступных иконок: https://ionic.io/ionicons
   
   - **Заголовок:** [Краткий заголовок преимущества]
     Пример: "Высокое качество материалов"
     Длина: 3-6 слов
   
   - **Описание:** [Подробное описание преимущества]
     Пример: "Использование сертифицированных материалов и компонентов нержавеющей стали 316L для максимальной долговечности"
     Длина: 1-2 предложения
   
   **Рекомендуется:** 4 преимущества для каждого продукта

## Рекомендации по изображениям

1. **Формат:** JPG или PNG
2. **Разрешение:** Минимум 1200x800px
3. **Соотношение сторон:** 3:2 или 16:9
4. **Качество:** Высокое, но оптимизированное для веб
5. **Содержание:** 
   - Четкое изображение оборудования
   - Хорошее освещение
   - Нейтральный фон
   - Профессиональная фотография

---

## Общие рекомендации

1. **Названия продуктов:** 
   - Используйте понятные и описательные названия
   - Включайте модель/серию, если применимо
   - Будьте последовательны в форматировании

2. **Описания:**
   - Краткое описание: фокус на ключевых особенностях
   - Полное описание: больше деталей о применении и преимуществах
   - Используйте профессиональную терминологию, но оставайтесь понятными

3. **Характеристики:**
   - Указывайте диапазоны значений, если применимо
   - Используйте стандартные единицы измерения
   - Будьте точными и честными

4. **Преимущества:**
   - Фокусируйтесь на выгодах для клиента
   - Используйте конкретные факты и цифры
   - Избегайте общих фраз без конкретики
